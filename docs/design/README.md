# Design (AARRS)

Hier dokumentieren wir Architektur- und Prozessentscheidungen kurz und nachvollziehbar.

## Inhalte
- `architecture.md` – Überblick über Komponenten/Ordner und ihre Verantwortlichkeiten
- `decision-log.md` – Entscheidungslog (ADR-lite)

## ADR-lite (Empfehlung)
Ein Eintrag sollte beantworten:
- Kontext: Warum war eine Entscheidung nötig?
- Entscheidung: Was wurde beschlossen?
- Konsequenzen: Was bedeutet das für Downstream-Integration?
