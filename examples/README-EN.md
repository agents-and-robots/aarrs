# Examples (AARRS)

This folder contains small, minimal examples that demonstrate:
- how a downstream repo can integrate AARRS,
- how prompts/constraints affect outcomes,
- how to apply “small diffs” and “human-in-the-loop” in practice.

## Planned

## Note
Examples are meant to teach patterns, not enforce a specific setup.
