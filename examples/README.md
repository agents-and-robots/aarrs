# Examples (AARRS)

Hier liegen kleine, minimalistische Beispiele, die zeigen:
- wie ein Downstream-Repo AARRS integriert,
- wie Prompts/Constraints wirken,
- wie man „small diffs“ und „human-in-the-loop“ praktisch umsetzt.

## Geplant
- kleines PHP-Repo als PoC
- Beispiel-Integration in ein größeres Repo (als Anleitung/Steps, keine „Fork-Pflicht“)
