# Templates (AARRS)

Hier liegt der Teil von AARRS, den du **in ein bestehendes Repository kopieren** kannst.

## Ziel
- minimale, vendor-neutrale AI-Readiness-Struktur zum Einbauen
- ohne das Ziel-Repo „umzubauen“
- mit klaren Einstiegspunkten für Mensch & KI

## Inhalt (geplant)
- `docs/ai/*` Bundle (Kontext, Constraints, Prompts)
- optionale GitHub Actions (nur wenn gewünscht)
- Beispiel-Checklisten/Scorecards

## Einbau (High-level)
1. Kopiere die gewünschten Dateien in dein Repo
2. Passe `docs/ai/repo_context.md` an (Ziele/Nicht‑Ziele, Architektur, Konventionen)
3. Passe `docs/ai/constraints.md` an (Teamregeln, CI, Security)
4. Optional: übernehme Prompts und ergänze domänenspezifische Rollen (z. B. „Magento Extension Reviewer“)
